# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects


## Overview

This repository showcases my coursework and practical exercises completed as part of my learning in Geographic Information Systems (GIS) using QGIS 3. Across these projects, I worked with real-world spatial datasets to learn how geographic data is collected, cleaned, analyzed, and presented. The tasks cover essential GIS workflows including working with vector and raster data layers, linking tabular data to map features, performing spatial analysis, and designing final print maps. Through these exercises, I developed foundational skills in geospatial data management, coordinate transformations, spatial querying, and map layout design.

## Skills Demonstrated

* Working with Coordinate Reference Systems (CRS) and layer re-projections
* Attribute table editing, field calculations, and non-spatial table joins
* Importing standalone spreadsheets and CSV files with spatial coordinates (X/Y data)
* Vector feature styling and categorized/graduated symbology design
* Basic raster visualization, and singleband pseudocolor styling
* Executing spatial joins to transfer attributes based on geographic location
* Performing spatial queries to isolate features using location relationships
* Extracting and filtering open-source vector datasets using the QuickOSM plugin
* Creating publication-ready maps with titles, legends, scale bars, and north arrows using QGIS Print Layout

## Reflection

Working through these hands-on tutorials made several key GIS concepts much clearer, especially how attribute tables connect directly to geometric features on a map and how non-spatial tabular data can be merged using table joins. I also gained a much better intuitive understanding of why choosing the correct Coordinate Reference System (CRS) matters when measuring distances and areas accurately across different regions. The most challenging part was troubleshooting spatial queries and joins when layer boundaries didn't align cleanly or when attribute data had mismatched field types that prevented successful table joins. Learning to clean data and double-check layer projections before running analyses helped me overcome those hurdles. Looking ahead, I anticipate using these skills to analyze spatial patterns for research projects, clean municipal open data, and design clear thematic maps for coursework, academic papers, and future professional projects.
